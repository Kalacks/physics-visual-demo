# 初中物理模型可视化教学平台

这是一个零依赖静态网页作品集，面向初中物理课堂投屏、学生探究和前端求职展示。

## 页面入口

- `index.html`：求职作品集入口，包含两个 demo 的介绍和内嵌预览。
- `motion_demo.html`：力与运动专项仿真。
- `portfolio_demo.html`：求职作品集入口备份页面。
- `demo_code/index.html`：五大物理模型合集，包含凸透镜成像、欧姆定律、浮力模型、杠杆平衡、物态变化曲线。

## 技术特点

- 原生 HTML/CSS/JavaScript，无构建工具和 npm 依赖。
- 使用 SVG 绘制仿真场景、图像曲线和力/光路示意。
- 支持拖拽、滑块参数调节、实时结论反馈。
- 采用明亮蓝色舞台、粗描边控件和卡片式入口，适合课堂投屏和作品展示。

## GitHub Pages 发布

上传到 GitHub 仓库后，在仓库设置中启用 Pages：

1. 进入 `Settings -> Pages`。
2. Source 选择 `Deploy from a branch`。
3. Branch 选择 `main`，目录选择 `/root`。
4. 发布后访问：

```text
https://你的用户名.github.io/仓库名/
```
